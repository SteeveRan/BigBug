# Каталог edge cases: Git Mirroring

> Living document: `docs/analitics/edge-cases/git-mirroring.md`. По одной таблице
> на пользовательскую операцию. Словарь — `GLOSSARY.md`. В колонке «Требуемое
> поведение» — без путей к файлам реализации: называй шов, не код.

## Overview

| Поле | Значение |
|-------|-------|
| Модуль | Git Mirroring |
| Назначение | Зеркалировать git-репозитории из GitHub в GitLab, поддерживать их актуальность, проверять целостность и восстанавливаться после дрейфа — BigBug оркестратор, перенос выполняют GitLab CI-пайплайны (ADR-0008). |
| Пользовательские операции | импорт группы источников, создание зеркала, массовое создание, sync зеркала, приём результатов sync, настройка sync-группы, freshness-проверка, integrity-проверка, orphaned discovery, orphaned remediation (владелец #160), удаление/восстановление зеркала |
| Permissions | `mirrors:read/write/delete/sync/import/integrity_check/manage_orphaned`, `source_groups:read/write/refresh`, `sync_groups:read/write/delete` |
| Связанные ADR | ADR-0008 (git mirroring GitHub→GitLab), ADR-0007 (providers), ADR-0025 (верификация webhook), ADR-0004 (RBAC), ADR-0039 (task-очередь) |
