## US-gitmrr-006: Проверить свежесть зеркала

### Story Header

| Поле | Значение |
|-------|-------|
| ID | US-gitmrr-006 |
| Название | Проверить свежесть зеркала |
| Персона | operator |

### User Story Statement

**Как** operator,

**я хочу** дешёвую ручную проверку свежести — сравнение источника с целью,

**чтобы** видеть, отстаёт ли зеркало от источника, не запуская полный sync.

### Context & Background

Freshness сравнивает последнее известное состояние коммита источника с записанным (ADR-0008). Проверка дешёвая — безопасно запускать часто, вручную и по расписанию. Поток: UC-gitmrr-007.

### Acceptance Criteria

#### AC-1: Вердикт — один из трёх

**Дано** зеркало со связанным source-репозиторием

**Когда** я запускаю freshness-проверку

**Тогда** система записывает результат FRESH, STALE или ERROR с временной меткой

#### AC-2: STALE виден на зеркале

**Дано** freshness-проверка вернула STALE

**Когда** я смотрю список или детали зеркала

**Тогда** зеркало несёт warning-состояние, учёт расшедшихся коммитов обновлён

#### AC-3: Непроверяемый источник — ERROR, не подделка

**Дано** провайдер источника недоступен или credentials невалидны

**Когда** я запускаю freshness-проверку

**Тогда** система записывает ERROR с причиной провайдера; прежнее состояние зеркала не подменяется фальшивым FRESH

### Technical Notes

- Требует `mirrors:sync` (как и ручной sync).
