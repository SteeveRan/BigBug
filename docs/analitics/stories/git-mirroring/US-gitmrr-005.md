## US-gitmrr-005: Настроить автоматический sync через sync-группу

### Story Header

| Поле | Значение |
|-------|-------|
| ID | US-gitmrr-005 |
| Название | Настроить автоматический sync через sync-группу |
| Персона | operator |

### User Story Statement

**Как** operator,

**я хочу** настроить cron-расписание и лимит конкурентности на sync-группе,

**чтобы** все зеркала группы поддерживались актуальными автоматически без настройки каждого, а API источника не перегружался.

### Context & Background

Sync-группа — единица расписания (ADR-0008): cron-строки для sync и freshness, лимиты конкурентности, включение/выключение. Изменение расписания должно вступать в силу без редеплоя или рестарта платформы (поток: UC-gitmrr-006).

### Acceptance Criteria

#### AC-1: Cron-расписание гоняет запуски

**Дано** sync-группа с включённым sync-cron

**Когда** cron срабатывает

**Тогда** система синхронизирует зеркала группы в пределах настроенного лимита конкурентности

#### AC-2: Изменение расписания действует без рестарта

**Дано** sync-группа, чей cron или флаг включённости я только что изменил

**Когда** наступает следующий cron-момент

**Тогда** запуски следуют новой конфигурации — без рестарта приложения между делом

#### AC-3: Выключенная группа не запускается

**Дано** выключенная sync-группа

**Когда** её cron-момент проходит

**Тогда** sync-запуски для её зеркал не стартуют

#### AC-4: Невалидный cron отклоняется при сохранении

**Дано** я ввожу некорректное cron-выражение (или строку длиннее лимита 100 символов)

**Когда** я сохраняю sync-группу

**Тогда** система отклоняет изменение с ошибкой по полю и сохраняет прежнее расписание

#### AC-5: Зеркала назначаются в группу массово

**Дано** до 100 зеркал

**Когда** я массово назначаю их в sync-группу

**Тогда** все перечисленные зеркала принадлежат этой группе; зеркала из других групп перемещаются

### Technical Notes

- `sync_groups:read/write/delete`; массовое назначение ≤ 100 за запрос; удаление default-группы запрещено, зеркала удаляемой группы мигрируют в default.
