## US-gitmrr-004: Запустить sync зеркала вручную

### Story Header

| Поле | Значение |
|-------|-------|
| ID | US-gitmrr-004 |
| Название | Запустить sync зеркала вручную |
| Персона | operator |

### User Story Statement

**Как** operator,

**я хочу** триггерить sync зеркала немедленно,

**чтобы** актуализировать цель, не дожидаясь расписания (например, сразу после релиза).

### Context & Background

Sync переносит код триггером CI-пайплайна целевого GitLab-проекта (ADR-0008). Оператор триггерит; пайплайн исполняется; результат возвращается асинхронно (US-gitmrr-008). Поток: UC-gitmrr-004.

### Acceptance Criteria

#### AC-1: Триггер принят, запуск записан

**Дано** зеркало с привязанной целью и настроенным пайплайном на его sync-группе

**Когда** я триггерю sync

**Тогда** система записывает запись sync-ранa, помечает зеркало In Progress и возвращает успех

#### AC-2: Ошибка конфигурации — именованная

**Дано** у sync-группы зеркала не настроен пайплайн

**Когда** я триггерю sync

**Тогда** система записывает skipped-ран с причиной «no pipeline configured» и показывает это на зеркале

#### AC-3: Результат виден

**Дано** запущенный sync завершился на стороне GitLab

**Когда** я смотрю зеркало

**Тогда** я вижу исход sync (completed/failed) и его временную метку

### Technical Notes

- Требует `mirrors:sync`. Триггер freshness использует то же право.
