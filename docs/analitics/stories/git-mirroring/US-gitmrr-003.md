## US-gitmrr-003: Массово создать зеркала

### Story Header

| Поле | Значение |
|-------|-------|
| ID | US-gitmrr-003 |
| Название | Массово создать зеркала |
| Персона | operator |

### User Story Statement

**Как** operator,

**я хочу** создавать зеркала для многих source-репозиториев одним действием,

**чтобы** подключение крупной source-группы не превращалось в десятки повторов диалога создания.

### Context & Background

Source-группы регулярно превышают 50 репозиториев. Массовое создание обязано валидировать весь батч заранее и отчитываться по-элементно (поток: UC-gitmrr-003).

### Acceptance Criteria

#### AC-1: Батч до 500

**Дано** до 500 source-репозиториев

**Когда** я отправляю массовое создание

**Тогда** система создаёт по зеркалу на элемент в одном запросе

#### AC-2: Превышение лимита отклоняется заранее

**Дано** батч больше 500

**Когда** я его отправляю

**Тогда** система отклоняет запрос целиком с сообщением о лимите и не создаёт ничего

#### AC-3: Несуществующие источники перечислены

**Дано** батч ссылается минимум на один неизвестный source-репозиторий

**Когда** я его отправляю

**Тогда** система отклоняет запрос, перечисляя неизвестные идентификаторы, и не создаёт ничего

### Technical Notes

- Требует `mirrors:write`. Семантика дубликата — как в US-gitmrr-002 AC-4 (advisory).
