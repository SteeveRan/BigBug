Необходимо внести следующие изменения:

п. 1. Страница http://localhost:5173/git-mirroring/sources?tab=repositories

На самой странице необходимо убрать таблицу Source Groups

Необходимо переделать форму. В ней мы должны указывать только url по которому будет выполняться копирование. Из URL должны рассчитываться:
1. Главная ветка
2. Название репозитория
3. SourceGroup
Форма добавления репозитория должна поддерживать: без кредов / с кредами (с тестом подключения и сохранением для переиспользования)


SourceGroup для репозитория должен рассчитываться автоматически из названия и типа. Если такой сорс группы нет она должна автоматически создаваться. source_provider_id должен быть на SourceRepository, а не на SourceGroup.


SourceGroup — чистая логическая группировка (GitHub org / GitLab group) без кредов. SourceProvider должен привязываться к репозиторию, а не SourceGroup. 

Когда мы добавляем репозиторий у нас есть выбор:
1. Не использовать никаких кредов (и соответсвенно провайдеров)
2. Поставить галочку, что нужна авторизация

Если галочка заполнена, то мы указываем далее и на новой форме заполняем данные для авторизации. Вторая форма зависит от типа провайдера и типа подключения.


Так же у нас должна быть возможность сохранить указанные креды для периспользования.

Таким образом Source Provider должен привязываться не к Source Group, а к каждому конкретному репозиторию. И в Source Group могут находиться репозитории, которые синкались разными кредами.

Удалить из модели SourceGroup поле source_provider_id. Проверить, что оно есть у репозитория. Группа соответственно автосоздаётся без всех этих заморочек.
